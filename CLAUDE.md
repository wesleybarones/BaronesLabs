# Preferências do Wesley

- Toda prévia do site deve ser entregue como link HTML (Artifact). Gerar um HTML único: rodar `INLINE=1 npx vite build`, embutir CSS e JS e republicar sempre no mesmo link: https://claude.ai/artifact/L2mAQ9VZfiBVaUE9LQAgnr
- Usar a foto `src/assets/wesley.jpg` como referência para qualquer imagem do Wesley no site.
- Logos oficiais: PNGs na raiz do repositório; versões otimizadas para o site em `src/assets/brand/` (symbol.webp e logo.webp).
